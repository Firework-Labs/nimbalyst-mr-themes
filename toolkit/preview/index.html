Mr. Themes Toolkit — Preview hub

How to use (5 lines): 1. Generate or hand-author a theme/family, then run node cli/mrthemes.mjs preview <file> to load it here. 2. This hub shows what's loaded and links to every page — tiles below are a quick pass/warn/fail glance per theme. 3. app.html shows the full window shell for one theme at a time (switch with the dropdown or ←/→). 4. components.html is the specimen sheet (every component, every state); contrast.html is the audit made visual; tokens.html lists all 75 variables; edge-cases.html renders every known failure mode live. 5. family.html compares every loaded theme side by side — use it when checking consistency across a family's six variants.
